# Telefy

Клиент Telegram для desktop, mobile и web написаный с нуля и для улучшения аспектов tg в сфере соцсети

## Быстрый старт

```bash
cp .env.example .env
flutter pub get
make run-web
```

Перед запуском укажите `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в `.env`.
